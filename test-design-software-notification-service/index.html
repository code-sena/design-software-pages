Objetivo

Clonar y entender de punta a punta el microservicio design-software-notification-service (Go, arquitectura hexagonal): API HTTP, consumer/publisher AMQP, patrón Outbox, y observabilidad OpenTelemetry. No se trata de escribir código nuevo — se trata de leerlo, correrlo, y poder explicarlo.

⚠️ Regla de oro

No vas a tocar código ni mover NADA. Esta actividad es de lectura y comprensión: clonás, corrés, leés y explicás el micro. No se modifica el código, no se commitea, no se hace push, no se mueve ni renombra nada del repo ni del tablero. El objetivo es entender el microservicio, no cambiarlo.

Dónde trabajás
